## 3. Git

**Keyword:** Git, Repository, Commit, Version Control

Git là công cụ quản lý phiên bản chạy trên máy tính.

Lệnh hằng ngày:

``` bash
git pull
git add .
git commit -m "..."
git push
```

## 4. GitHub

**Keyword:** Cloud, Remote Repository

GitHub là nơi lưu trữ repository trên Internet để đồng bộ và sao lưu.

## 5. Git và GitHub

-   Git: quản lý phiên bản.
-   GitHub: lưu trữ và đồng bộ.

Quy trình:

``` text
Laptop
   ↓
git push
   ↓
GitHub
   ↓
git pull
   ↓
PC
```
